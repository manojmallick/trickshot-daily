# Trickshot Daily

Trickshot Daily is a browser physics puzzle prototype. Aim a shot around obstacles and try to sink the ball. The daily puzzle is generated deterministically from the date, so players see the same layout for a given day.

## Run

```bash
pnpm install
pnpm dev
```

Drag from the ball to aim, then release to shoot.

## Build

```bash
pnpm build
pnpm typecheck
```

Game logic is organized under `src/logic/`.
